# Triage labels

Each triaged issue carries exactly one category and one state. Flag conflicting
states before changing an existing issue.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| bug | `bug` | Existing behavior is broken. |
| enhancement | `enhancement` | New behavior or an improvement. |
| needs-triage | `needs-triage` | Maintainer evaluation is needed. |
| needs-info | `needs-info` | More information is needed from the reporter. |
| ready-for-agent | `ready-for-agent` | Behavior and acceptance criteria are specified. |
| ready-for-human | `ready-for-human` | Human implementation or judgment is needed. |
| wontfix | `wontfix` | The request will not be actioned. |
